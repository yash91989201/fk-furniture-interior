# Fix the performance audit findings before SEO

## Summary

Fix delivery weight, mobile LCP, enquiry behavior, and confirmed accessibility defects. The audit at `250f7aa` recorded **7.1–8.3 s mobile LCP** on About, Services, Projects, and Resort De Coracao. Its Python static server provides an uncompressed baseline. Use the actual nginx delivery path for the before-and-after comparison. MilesWeb/cPanel is the documented launch host. [Audit](README.md) · [Deployment guide](../../output/milesweb-deployment-guide.md)

## Implementation

1. **Fix static delivery.** Enable gzip for HTML, CSS, JavaScript, and other compressible text in Docker nginx. Give content-hashed `/assets/` one-year immutable caching. Require revalidation for HTML and keep replaceable public images out of the immutable policy. Document equivalent cPanel rules and merge them into the host configuration only if preview headers show they are needed. Preserve HTTP 404s for unknown paths and missing assets. [nginx gzip docs](https://nginx.org/en/docs/http/ngx_http_gzip_module.html) · [Apache compression docs](https://httpd.apache.org/docs/2.4/mod/mod_deflate.html)
2. **Shrink the images on the critical path.** Generate 720w and 1280w WebP variants for `guest-bath`, `corridor`, `meeting`, and `office-building`. Use accurate `sizes` and `srcSet` on heroes and cards. Fix About’s missing `corridor-1280.webp`. Make both Home hero layers select the same responsive candidate. Lazy-load furniture backdrops, remove decorative logo preloads, and use display-sized WebP derivatives for the navigation and footer logos. Keep the original brand assets.
3. **Reduce render-blocking CSS and font weight.** Keep shared navigation, footer, and base styles global. Load home-only section styles with the Home route and keep shared enquiry styles available on Home, About, and FAQ. Keep the three Latin font faces the site uses and verify glyph coverage and typography. If traces still show a startup bottleneck, defer Lenis initialization until after hydration and retest. Preserve prerendered content and existing interaction behavior.
4. **Make enquiries work safely.** Keep the Home, About, and FAQ forms and reuse `buildEnquiryMailto`. Label the action **Open email draft**, preserve furniture presets and Gallery references, and preselect **Factory visit** on About. On all five form pages, keep controls disabled until hydration and expose direct email and phone links in the static HTML. Verify mouse and Enter-key submission with JavaScript off sends no request containing personal data.
5. **Fix confirmed accessibility and markup defects.** Use foreground text for Services step numbers. Include **View photograph** in Gallery buttons’ accessible names. Close the mobile menu with Escape and return focus to its summary. Give project cards valid block markup and a project heading. Label office address and phone groups, make privacy contact details actionable, expose FAQ question IDs, and point the Terms skip link to the first clause.

## Verification and handoff

- Build and type-check. Run targeted Ultracite and enquiry tests. Check generated pages for missing assets. Smoke-test mobile and desktop navigation, the Gallery lightbox, email draft contents, and JavaScript-off fallbacks.
- Run three Lighthouse passes per device on all ten routes against the same nginx configuration. Report medians and transferred bytes. Use **90+ mobile Performance**, **LCP below 4 s**, **CLS ≤0.1**, and **TBT ≤200 ms** as the pre-SEO gate. Aim for **LCP ≤2.5 s**. If a route misses the gate, report its remaining bottleneck before advancing. [Web Vitals](https://web.dev/articles/vitals)
- Handle canonicals, trailing-slash links, social tags, sitemap, structured data, metadata copy, and branded 404 in the SEO pass. Verify the production domain first. Require legal approval before indexing the draft policies, or apply `noindex` in that pass. Team photography and a project-detail lightbox can wait for approved assets or a separate feature decision.
